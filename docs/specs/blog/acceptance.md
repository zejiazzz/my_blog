# Acceptance

## 正常路径

- 首页只展示已发布文章。
- Skills 页只展示已发布 Skills。
- Skill 详情能展示标题、摘要、分类、标签和正文。
- 管理员可以新建、编辑、删除 Skill。

## 边界路径

- 空文章列表显示空状态。
- 空 Skills 列表显示空状态。
- 英文内容为空时，英文语言下回退中文内容。
- tags 为空时不渲染标签区域。

## 异常路径

- 未登录访问 `/admin/skills` 重定向到 `/login`。
- 不存在的 Skill slug 返回 404。

## 回归点

- `posts` 和 `skills` 不共表。
- 数据库不再保留旧的 Skills 单页表。
- 自动生成内容和定时任务不属于当前需求范围。
